# NVM Express Consortium

The industry consortium that owns and publishes the NVMe specification family. Website: nvmexpress.org. Contact: info@nvmexpress.org.

## Role

Develops and maintains the NVMe Base Specification, NVM Command Set Specification, Key Value Command Set, Zoned Namespace Command Set, and all transport binding specifications (PCIe, TCP, RDMA, FC). Also publishes NVMe-MI (Management Interface) and NVMe Boot specifications.

Members include major storage, semiconductor, and systems companies (Intel, Samsung, Western Digital, Micron, Seagate, NVIDIA, Broadcom, Marvell, and others).
